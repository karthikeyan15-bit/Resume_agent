Agent 1 — agents/jd_parser.py
JD Parser Extracts role, required skills, preferred skills, responsibilities, keywords → parsed_jd dict
Input: jd_text → Output: parsed_jd dict
Agent 2 — agents/resume_evaluator.py
Resume Evaluator Scores resume vs JD across 5 dimensions · matched skills · missing skills · verdict → evaluation dict
Input: resume_text + parsed_jd → Output: evaluation dict
Agent 3 — agents/gap_analyst.py
Gap Analyst Critical gaps · what company wants · 3 project suggestions · quick wins → gap_analysis dict
Input: resume + parsed_jd + evaluation → Output: gap_analysis dict
Agent 4 — agents/resume_writer.py
Resume Writer Rewrites resume aligned with JD · injects keywords · adds suggested projects → final_resume string
Input: all previous outputs → Output: final resume text
