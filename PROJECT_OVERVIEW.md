# Resume Agent

## Project Overview

Resume Agent is an AI-oriented application for assisting with resume creation and improvement. It organizes resume-related tasks into agent and graph components so workflow stages can be coordinated and tested independently.

## Main Areas

- `agents/` — Specialized resume-processing agents.
- `graph/` — Workflow orchestration and task flow.
- `app.py` — Main application entry point.
- `llm_config.py` — Language-model configuration.
- `test_*.py` — Tests for agents, setup, and pipeline behavior.

The project explores how agentic workflows and language models can help users structure professional information, generate resume content, and refine applications.
