Resume Builder — Tech Stack
Every tool, framework, and LLM used in the 4-agent pipeline
Frontend
streamlit
Streamlit Web UI · 5 tabs · file uploader · st.download_button · st.status()
Run with: streamlit run app1.py — opens at localhost:8501
Agent orchestration
langgraph
LangGraph StateGraph · sequential pipeline · ResumeState TypedDict
Wires all 4 agents with add_node() and add_edge() — compiles into one callable pipeline
langchain
LangChain LCEL chains · PromptTemplate · StrOutputParser
The pipe operator | connects prompt → LLM → parser inside every agent
langchain-groq
langchain-groq LangChain ↔ Groq bridge · ChatGroq class
Adapter that makes Groq work with LangChain's standard interface
LLM providers — swap via llm_config.py
groq
Groq — Primary Llama 3.1 · free · no credit card · fastest inference
DEFAULT_PROVIDER = "groq" in llm_config.py — used in this workshop
google-generativeai
Gemini — Alt gemini-2.0-flash · free tier · Google account
Change DEFAULT_PROVIDER = "gemini" — get key at aistudio.google.com
langchain-ollama
Ollama — Alt Runs locally · no API key · llama3.1 / mistral
Change DEFAULT_PROVIDER = "ollama" — needs Ollama installed locally
File handling
pdfplumber
pdfplumber PDF text extraction · page by page · handles multi-page resumes
Used in pdf_extractor.py — opens PDF, loops pages, joins all text
python-docx
python-docx DOCX read + write · paragraph extraction · final resume output
Reads DOCX resumes AND generates the final tailored_resume.docx download
python-dotenv
python-dotenv Loads .env file · os.getenv() for API keys
load_dotenv() at top of every file reads GROQ_API_KEY etc. from .env
Web scraping — jd_scraper.py
httpx
httpx HTTP requests · async-ready · follows redirects
Fallback scraper — works for static job pages. Sends browser-like User-Agent header
beautifulsoup4
BeautifulSoup4 HTML parsing · strips nav/footer/scripts · clean text
Parses raw HTML from httpx, removes junk tags, returns clean readable JD text
firecrawl-py
Firecrawl JS-heavy sites · LinkedIn · Greenhouse · Lever
Primary scraper — handles JavaScript-rendered pages that httpx can't read. Optional API key
Environment
python 3.10+
Python 3.10+ Runtime · TypedDict optional keys · match statements
Minimum 3.10 — LangGraph's TypedDict with Optional fields requires it
venv
Virtual Environment Isolated packages · no system conflicts · activates with Scripts/activate
python -m venv resume → resume\Scripts\activate on Windows
.env
.env file GROQ_API_KEY · GEMINI_API_KEY · FIRECRAWL_API_KEY
Never commit to GitHub. Add to .gitignore. Use .env.example as a template
pip install streamlit langchain langchain-groq langchain-google-genai langchain-ollama langgraph groq google-generativeai pdfplumber python-docx httpx beautifulsoup4 python-dotenv firecrawl-py
